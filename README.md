# Hookah Plugin

Minecraft Paper plugin for a hookah mechanic.

## Features
- smoking effect on brewing stands
- smoke particles and smoke rings
- configurable effects
- simple reload/status commands

## Build

```bash
mvn clean package
```

## Commands

- `/hookah reload`
- `/hookah status`

## Requirements
- Java 21
- Paper 1.21+
